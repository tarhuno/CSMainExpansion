# 0.3.6.11-dev — команды событий карты и срок действия комплекта Escort

## Команды событий

```
/csx onmap start time set day
/csx onmap start weather clear
/csx onroundstart effect clear @a
```

Текст после start/onroundstart — одна обычная команда Minecraft без начального `/` (начальный слэш также принимается и убирается). Повторный ввод добавляет следующую команду; записи выполняются по порядку. Вложенный execute, селекторы, NBT и JSON передаются без переписывания синтаксиса. Неизвестные или неуспешные команды обнаруживаются при выполнении, а не при сохранении.

Списки сохраняются в hooks.start и hooks.round JSON выбранной карты, отдельно для разных карт и измерений. Они общие для режимов Bomb/Escort/Duel на этой карте. Имеющиеся карты без hooks получают пустые списки; прочие поля карты сохраняются.

- onmap start срабатывает один раз при старте матча — после начала разминки, телепортации и стартовой выдачи.
- onroundstart срабатывает один раз на каждый настоящий старт раунда, включая первый после разминки, в начале FREEZE после телепортации и выдачи экипировки. На каждом респавне разминки он не запускается.
- Выполнение идёт от серверного источника с уровнем прав 2 в измерении карты. Позиция источника — первый CT-спавн, иначе первый T-спавн, иначе спавн мира. У источника нет игрока для @s; для таких команд нужно явно использовать execute as/at. Селектор @a по обычным правилам Minecraft не означает автоматически только участников матча.
- Вложенный запуск матча/раунда из самой команды не запускает события рекурсивно. Список копируется до выполнения: изменение настроек самим скриптом влияет на следующее событие. Ошибка отдельной команды не прерывает остальные записи; результат 0 и исключения отмечаются в серверном логе.

Просмотр:

```
/csx onmap start
/csx onroundstart
/csx onmap list start
/csx onmap list round
```

Удаление:

```
/csx onmap remove start 1
/csx onmap remove round 1
/csx onmap clear start
/csx onmap clear round
```

Все эти команды настройки требуют прав оператора 2. Управление списками вынесено отдельно, поэтому `/csx onroundstart clear @a` сохраняет именно Minecraft-команду clear, а не очищает настройки событий.

## Escort

Право на комплект теперь записывается при успешной покупке escort_kit, независимо от оставшихся предметов в инвентаре. Пока игрок жив, остаётся CT в том же матче/карте и не стал наблюдателем, следующий раунд восстанавливает ровно одно седло и одну морковную удочку с полной прочностью — даже если седло уже потрачено или удочка сломана.

Смерть отзывает право и удаляет седло/удочку из инвентаря, второй руки и курсора. Обработаны Clone после смерти и keepInventory; оставшиеся/поздно восстановленные предметы не дают комплект снова. При ручной смене стороны, переходе в spectator и смене половин право отзывается. Новые CT не получают набор без покупки; T не могут сохранить его. Новый матч и окончание матча очищают право. Купленный на разминке комплект не переносится через очистку первого игрового раунда.

Предметы комплекта помечаются; выпавшие помеченные предметы включены в существующую очистку дропа перед следующим спавном. Поднятый предмет сам по себе не даёт право на восстановление. Обычные седла/удочки вне Escort-матча не удаляются, если не помечены как комплект. При переподключении в LIVE spectator-переход также прекращает владение; в WARMUP/FREEZE без смерти и смены стороны владение может сохраниться до конца этого матча.

Проверить list, remove по номеру и clear. На карте B списки пустые; после возврата и перезапуска сервера записи A сохранены.
2. Для точного счёта создать scoreboard objective csx_hooks типа dummy, затем сохранить start-команду `scoreboard players add match csx_hooks 1` и round-команду `scoreboard players add round csx_hooks 1`. При старте разминки match увеличивается один раз; смерти на разминке не увеличивают round. При каждом FREEZE round увеличивается один раз, включая первый раунд и раунд после смены половин. Повторить Bomb, Escort и Duel.
3. Проверить команды execute, селекторы и tellraw/NBT без потери кавычек. Проверить контекст другого измерения. Сохранить неизвестную команду между двумя рабочими: матч не должен падать, остальные команды выполняются, диагностика есть в логе. Без прав оператора настройка недоступна.
4. Escort CT покупает набор, расходует седло, повреждает/ломает удочку и выживает. Следующий раунд даёт один новый комплект с полной прочностью без повторной оплаты. Проверить полный инвентарь: покупка выдаёт/роняет оба предмета и регистрирует комплект. Повторные раунды не накапливают предметы.
5. Повторить смерть с keepInventory=false и true, с удочкой во второй руке и предметом на курсоре. После респавна/следующего раунда набора нет; нужно купить заново. Сам оставшийся предмет не возобновляет право. Поднять чужой комплект — автоматического права восстановления нет.
6. Проверить автоматическую смену половин и `/csx team ... t`, затем возврат CT: старый комплект не возвращается. Новый CT покупает набор заново. Проверить spectator, остановку/новый матч и смену режима/карты. Вне матча непомеченное седло и обычная морковная удочка сохраняются.
7. Регрессии: Duel/настройки режимов, магазин и зоны, синхронизация каталога LAN, респавн/видимость, броня, техническая пауза, декои и очистка свиней.
