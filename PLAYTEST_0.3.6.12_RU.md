# 0.3.6.12-dev — JSON-каталог ножей

Обновить Expansion на сервере и клиентах. Требуются соответствующие пакеты ножей CS2 WT / cswt+: Expansion выбирает их ID, но не содержит модели и текстуры.

## Конфигурация

При регистрации серверных команд загружается `config/csmainexpansion/knives.json` в каталоге экземпляра Minecraft/сервера. Файл общий для сервера, не зависит от выбранной карты. Если отсутствует, создаётся с таким содержимым:

```json
{
  "butterfly": {
    "ruby": "cswtplus:buruby",
    "emerald": "cswtplus:buemerald",
    "sapphire": "cswtplus:busapphire",
    "blackpearl": "cswtplus:bublackpearl"
  },
  "karambit": {
    "ruby": "cswtplus:karruby",
    "emerald": "cswtplus:karemerald",
    "sapphire": "cswtplus:karsapphire",
    "blackpearl": "cswtplus:karblackpearl"
  },
  "m9": {
    "ruby": "cswtplus:m9ruby",
    "emerald": "cswtplus:m9emerald",
    "blackpearl": "cswtplus:m9blackpearl"
  },
  "stiletto": {
    "ruby": "cswtplus:stilettoruby",
    "emerald": "cswtplus:stilettoemerald",
    "blackpearl": "cswtplus:stilettoblackpearl"
  }
}
```

JSON дополняет встроенный каталог, совпадающие пары нож/скин переопределяются. Например butterfly emerald из примера заменяет cs2_wt:buemerald на cswtplus:buemerald. Остальные встроенные варианты, включая default, сохраняются. Удаление записи из JSON отменяет соответствующее дополнение/переопределение после reload; пустой объект `{}` оставляет только встроенный каталог. Существующий файл никогда автоматически не дополняется и не перезаписывается.

Можно добавлять полностью новые семейства ножей, указав у нового семейства `default` и нужные скины. Имена ножей и скинов состоят из строчных латинских букв, цифр и `_`. Значения — полные Minecraft ID `namespace:path`; префикс cs2_wt больше не добавляется автоматически. Проверяется синтаксис ID; наличие модели в установленном пакете проверяется игровым тестом.

Пример нового семейства (ID заменить реальным):

```json
{
  "customknife": {
    "default": "example:customknife",
    "ruby": "example:customknife_ruby"
  }
}
```

## Команды

```
/csx knives
/csx knives reload
/csx knife karambit
/csx skin karambit ruby
/csx knife butterfly
/csx skin butterfly blackpearl
/csx skins butterfly
```

Reload требует прав оператора 2. Остальные команды выбора сохраняют прежние правила доступа. Старая команда `/csx knifes` сохранена. Автодополнение knife/skin/skins читает актуальный каталог; skin также подсказывает скины огнестрельного оружия.

Выбор сохраняется обычной системой персональных настроек. Применяется при следующей выдаче/обработке раундовой экипировки, существующий нож прямо командой reload не заменяется. Если ранее выбранный скин удалён, выдаётся default этого ножа; если удалено всё пользовательское семейство — css. Стандартный css тоже использует полный ID из каталога.

Файл сначала полностью читается и проверяется, затем заменяется неизменяемый снимок каталога. При ошибке сохраняется предыдущий рабочий снимок, ошибка отображается оператору (при запуске — в серверном логе). При ошибке первой загрузки доступны встроенные ножи. Ошибочный файл не исправляется автоматически.

## Свиньи Escort

Для выбранной карты оператор стоит в нужной точке и выполняет `/map escort spawn add`; повторяет для каждой точки. `/map escort count 2` задаёт число свиней, `/map escort status` показывает настройки, `/map escort spawn clear` удаляет все точки. Зона эвакуации задаётся `/map escort evac pos1` и `/map escort evac pos2` из соответствующих углов. Эти команды уже существовали, их поведение в этом обновлении не менялось.

## Проверка

Java 17 `clean build`, включая reobfJar, прошёл. Прошли 11 автономных тестов с assertions. Новый KnifeCatalogTest проверяет создание файла, встроенные и новые ID, дополнение/переопределение, новое семейство с default, отсутствие перезаписи файла, удаление дополнений, неизменяемость снимка, отклонение повреждённого JSON/неверных ID/структуры и сохранение прежнего снимка при ошибке.

Minecraft/LAN-проверка пока НЕ выполнена. В первую очередь проверить:

1. Запуск сервера без файла: создаётся knives.json, старые ножи и новые варианты видны в `/csx knives`, `/csx skins <knife>` и TAB.
2. Выбрать karambit ruby и butterfly blackpearl, получить свежий нож на новом раунде; проверить модель, текстуру и `MeleeWeaponId` через `/data get entity <player> SelectedItem`. Должен быть один полный ID cswtplus:..., без cs2_wt:cswtplus:.
3. Поочерёдно проверить все 14 новых/переопределённых записей; особенно emerald у butterfly/m9, чтобы отличить cswtplus от встроенного варианта. Проверить m9 sapphire и прочие старые скины, не указанные в JSON.
4. Изменить JSON во время работы, выполнить reload: подсказки обновляются без перезапуска, следующий нож использует новое значение. Для нового семейства указать default. После перезапуска выбор и каталог сохраняются. Неоператор не может reload.
5. Сломать JSON или ID: reload сообщает ошибку, прежние ножи продолжают выдаваться. Исправить файл и повторить. Удалить пользовательскую запись: она исчезает из подсказок, старый выбор безопасно возвращается к default/css.
6. Проверить Bomb/Escort/Duel, разминку, старт раунда и отсутствие личного выбора ножа. Огнестрельные скины, глушители и магазин продолжают работать.
